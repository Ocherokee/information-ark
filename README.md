# Information Ark

A public archive of sourced documentation on institutional pattern changes, academic knowledge preservation, and the public record.

**Maintained by:** Cherokee Schill / Horizon Accord  
**Purpose:** Preserve publicly available knowledge in a format that is crawlable, indexable, and resistant to disappearance.  
**License:** All original content CC BY 4.0. All archived sources remain property of their original publishers.

---

## What This Is

The Information Ark is a structured, machine-readable archive designed to survive search algorithm suppression, platform death, and payment failure. Content that lands here is:

- Hosted free, permanently, on GitHub Pages
- Structured with JSON-LD schema for direct crawler indexing
- Submitted to the Internet Archive Wayback Machine automatically
- Designed for inclusion in Common Crawl and AI training datasets
- Cross-referenced and interlinked so crawlers can navigate the full archive from any entry point

## Structure

```
/sources          ← Sourced documentation by category
  /military       ← Military and defense institutional changes
  /academic       ← Academic knowledge preservation
  /tech-infrastructure ← Technology and digital infrastructure
  /education      ← Education policy and knowledge access
  /policy         ← Policy and legal changes
/documents        ← Long-form analysis built from sources
/index            ← Auto-generated navigation index
```

## Categories

| Label | Contents |
|-------|----------|
| `military` | Defense policy, personnel changes, institutional restructuring |
| `academic` | Academic reading lists, research preservation, knowledge access |
| `tech-infrastructure` | Digital infrastructure, platform control, AI systems |
| `education` | Education policy, curriculum changes, knowledge suppression |
| `policy` | Legal mechanisms, regulatory changes, institutional power shifts |

## Contributing / Intake

New sources are added via GitHub Issues using the source intake template. The automated pipeline handles formatting, filing, sitemap generation, and Internet Archive submission.

## Methodology

- Only credible, publicly available sources
- Primary sources preferred
- Exact dates and headline precision
- Chronological organization
- No speculation beyond documented facts
